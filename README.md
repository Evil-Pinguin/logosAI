# LogosAI

> **Автоматизация генерации интерактивных логопедических уроков для детей с особенностями развития на базе ИИ.**  
> Платформа для логопедов и дефектологов, которая превращает лексическую тему в готовый интерактивный урок в стиле Duolingo/Wordwall — с визуальным расписанием (PECS), игровыми механиками и озвучкой.

---

## ✨ Возможности

### 🧠 ИИ-генерация контента
- Генерация структурированного JSON-урока через LLM (OpenAI GPT-4o-mini) по лексической теме и уровню сложности.
- Жёсткая валидация ответа модели на сервере с помощью **Zod-схемы** перед сохранением в БД и отдачей на фронтенд.
- Поддержка **JSON Mode** — модель возвращает чистый JSON без маркдаун-обёрток.
- Механизм **retry (до 3 попыток)** с обратной связью об ошибке валидации, если LLM вернул некорректный формат.

### 🎮 Игровой движок
- Состояние игры управляется через **Zustand** (урок, шаг, жизни, очки, прогресс).
- Плавные переходы между экранами и анимации карточек на **Framer Motion**.
- Четыре типа интерактивных упражнений:
  - `choice` — выбор правильной карточки из сетки со звуковым откликом.
  - `match` — соединение пар карточек линиями между двумя колонками.
  - `sequence` — расстановка 3 карточек в правильном порядке.
  - `exclude` — поиск лишней карточки из 4 с текстовым объяснением (`reason`).
- Экран **PECS-расписания** (визуальное расписание занятия) перед началом игр.
- Шкала прогресса, 3 жизни, счётчик очков, экран финиша с конфетти (`react-confetti`).

### ♿ Доступность и UX для детей с РАС
- Чистый, минималистичный интерфейс без визуального шума — подходит для детей с расстройствами аутистического спектра.
- Крупные, легко кликабельные элементы управления.
- Яркие контрастные акценты на белом/светлом фоне.
- **Web Speech API** для озвучки инструкций и текстов карточек на русском языке (скорость ≈ 0.85 для комфортного восприятия).

### 🔒 Безопасность данных
- **Supabase Auth** — регистрация и вход по Email/Password, OAuth через GitHub.
- **Row Level Security (RLS)** на всех таблицах — пользователь имеет доступ только к своим профилю, урокам и прогрессу.
- Автоматическое создание профиля (`profiles`) при регистрации нового пользователя через триггер Supabase Auth.

## 🛠 Технологический стек

### Frontend
- **React 18** + **TypeScript** — строгая типизация и componentes-ориентированная архитектура.
- **Vite** — быстрая сборка и dev-сервер.
- **Tailwind CSS v4** — утилитарная стилизация.
- **Zustand** —_lightweight_ состояние игрового движка.
- **Framer Motion** — анимации переходов и интерактивных карточек.
- **Lucide React** — набор иконок.
- **Zod** — валидация данных на клиенте.
- **react-confetti** — эффект конфетти на экране финиша.
- **React Router DOM** — навигация между страницами.

### Backend / BaaS
- **Supabase** — PostgreSQL, Auth, Edge Functions, Row Level Security.
- **pgcrypto** — генерация UUID.

### AI Integration
- **OpenAI SDK** (GPT-4o-mini) через Supabase Edge Function.
- Системный промпт `LogosAI Agent` с требованиями к дизайну и структуре урока.

## 🗄 Архитектура данных

База развёрнута на **Supabase (PostgreSQL)** с включённым **Row Level Security (RLS)** на всех таблицах:

| Таблица | Назначение | Ключевые поля |
|---------|------------|---------------|
| `profiles` | Профили пользователей (логопед / родитель) | `id` → `auth.users`, `full_name`, `role` (`speech_therapist` / `parent`) |
| `lessons` | Сгенерированные ИИ уроки | `id`, `user_id`, `title`, `lexical_theme`, `difficulty_level`, `raw_json` (JSONB) |
| `student_progress` | Аналитика прохождения уроков | `lesson_id`, `user_id`, `completed_at`, `score`, `lives_wasted` |

**Безопасность:** доступ к строкам ограничен на уровне БД — пользователь может читать и изменять только свои записи (`auth.uid() = user_id`). Логопед не чужих уроков, родитель не чужих результатов.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Evil-Pinguin/logosAI.git
cd logosAI
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Заполните переменные:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_OPENAI_API_KEY=sk-...
VITE_EDGE_FUNCTION_URL=https://your-project.supabase.co/functions/v1/generate-lesson
```

### 4. Инициализация базы данных
Выполните скрипт `supabase/init_database.sql` в **Supabase SQL Editor** — он создаст таблицы, триггер автосоздания профиля, индексы и политики RLS.

### 5. Развёртывание Edge Function
```bash
supabase functions deploy generate-lesson
supabase secrets set OPENAI_API_KEY=sk-...
```

### 6. Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.
